# Heartlightia 💗

A Venusian Earth-loving space where beings co-create with authentic joy and conscious awareness in sovereign interdependent communion with the Rays of ALL.

## Tech Stack

- Astro + Tailwind CSS v4
- Alice + Inter fonts
- Vercel deployment

## Commands

| Command | Action |
|:---|:---|
| `npm install` | Install dependencies |
| `npm run dev` | Start dev server at localhost:4321 |
| `npm run build` | Build production site to ./dist/ |
| `npm run preview` | Preview the build locally |

## Sacred Palette

Violet, Green, Gold, Rose Gold, Magenta. Green as the background hue.
